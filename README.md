# 📸 Responsive Personal Image Gallery

A lightweight and visually appealing personal image gallery project. This gallery utilizes the **Bootstrap 5 Grid System** to ensure a seamless viewing experience across various screen resolutions.

## 🚀 Key Features
- **Fully Responsive:** Adapts dynamically to different screen sizes:
  - **Mobile:** 1 column (`col-12`)
  - **Tablets:** 3 columns (`col-md-4`)
  - **Laptops:** 4 columns (`col-lg-3`)
  - **Desktop:** 6 columns (`col-xl-2`)
- **Uniform Layout:** Uses `object-fit: cover` to maintain consistent image proportions without distortion.
- **Clean UI:** Minimalist design with rounded corners and optimized spacing.

## 🛠️ Built With
- [HTML5](https://developer.mozilla.org) - Structure of the gallery.
- [CSS3](https://developer.mozilla.org) - Custom styling and layout refinements.
- [Bootstrap 5.3](https://getbootstrap.com) - Responsive grid system and utility classes.
